// design notes
Frame uses direct M5 screw-into-tapped-centre-hole method where possible — cleaner assembly, fewer parts, no hidden bracket cost. Drilling jig (printed PA-CF with metal insert) ensures repeatable hole position across all frame joints. Corner brackets used only where direct tapping is geometrically insufficient.

// power architecture
24V main bus (same as Prusa MK3S ecosystem). Better stepper torque at speed, lower wiring losses, standard spindle voltage. RECOM R-78E modules handle 24V→5V and 24V→3.3V for all logic. Mean Well LRS-150-24 available at GME, 15 min walk.

// registration pins
Spoilboard carries two steel dowel pins at known coordinates for 2-sided PCB flipping. Same technique used in dad's woodworking — proven concept, tighter tolerances. Enables double-sided PCB production covering ~90% of real board designs.

// software stack
GRBL-ESP32 for real-time step generation · KiCad → FlatCAM → G-code pipeline · ROS2 Python on Raspberry Pi for job management and future automation · LVGL display for local machine state — no laptop required for running a job. rev 0.1 — design phase
